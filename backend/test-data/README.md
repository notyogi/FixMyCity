# Test Image Dataset for Perceptual Hash Calibration

This directory contains test image pairs used to calibrate the `DEDUP_HAMMING_THRESHOLD` for duplicate report detection in FixMyCity.

## Directory Structure

```text
test-data/
├── similar-pairs/        # Pairs of images showing the SAME civic issue (different angle/lighting/distance)
├── dissimilar-pairs/     # Pairs of images showing DIFFERENT, unrelated issues or scenes
├── calibration-results.txt # Output generated by npm run calibrate:threshold
└── README.md
```

## Image Naming Convention

Place image pairs directly into their respective folders using the `pair<N>_a.<ext>` and `pair<N>_b.<ext>` naming convention:

- **Similar Pairs** (`/similar-pairs/`):
  - `pair1_a.jpg` & `pair1_b.jpg` (e.g., pothole from 2 meters vs. pothole from 5 meters)
  - `pair2_a.png` & `pair2_b.png` (e.g., broken streetlight by day vs. dusk)
  - `pair3_a.jpeg` & `pair3_b.jpeg`
  - ...
- **Dissimilar Pairs** (`/dissimilar-pairs/`):
  - `pair1_a.jpg` & `pair1_b.jpg` (e.g., pothole vs. garbage pile)
  - `pair2_a.png` & `pair2_b.png` (e.g., sidewalk crack vs. park bench)
  - `pair3_a.jpeg` & `pair3_b.jpeg`
  - ...

### Supported Image Formats
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

## How to Run Calibration

Once you have added test pairs to the folders, execute:

```bash
npm run calibrate:threshold
```

This will:
1. Compute the 64-bit perceptual hash (pHash) for both images in each pair directly from local disk.
2. Calculate the Hamming distance (0–64 bits) between each pair.
3. Print summary statistics (min, max, average, median) for both groups.
4. Recommend an optimal `DEDUP_HAMMING_THRESHOLD` or warn of overlapping distance ranges.
5. Save the full output report to `test-data/calibration-results.txt`.
